# ☕ 모닝빈 카페 랜딩 페이지

가상의 카페 "모닝빈"을 소개하는 간단한 정적 랜딩 페이지입니다. HTML과 CSS만으로 만들어서 별도의 빌드나 설치 없이 바로 열어볼 수 있습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 소개, 오시는 길, 푸터) |
| `style.css` | 스타일시트 (카페 분위기의 갈색 톤, 모바일 반응형) |

## 사용 방법

`index.html` 파일을 브라우저에서 열면 됩니다.

## 참고

카페 이름, 메뉴, 가격, 주소, 전화번호는 모두 예시용 임의 값입니다. 실제 정보에 맞게 `index.html`을 수정해서 사용하세요.
